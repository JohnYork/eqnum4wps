# eqnum4wps — WPS 文字公式自动编号

在 WPS 文字（Linux）中为公式自动编号的加载项。支持按章编号 `(2.1)` 与全文连续编号 `(1)`，
用两栏表格排版公式与编号，并提供原生交叉引用的插入与自动修复。

## 主要功能

- **编号当前公式**：对光标所在公式编号，不触发全文重排；混排公式会先拆成独立段落。
- **本章重编号 / 全文重编号**：批量重排已有编号的公式，倒序处理避免对象失效。
- **按章联动**：编号域为 `STYLEREF <层级> \n` + `SEQ 公式 \s <层级>`，章号变化后自动跟随。
- **两栏表格排版**：左栏公式居中，右栏编号右对齐，表格宽度对齐版心；无边框，保存后结构稳定。
- **插入引用**：调用 WPS 原生交叉引用（整项题注），引用是标准 `REF` 域。
- **引用自动修复**：重编号后在新的编号位置重建同名 `_Ref` 书签，正文引用无需改写，按 F9 即显示新编号。
- **进度与中止**：批量处理时显示进度条，可随时中止；每条公式后留出可配置的界面响应时间。
- **设置抽屉**：编号模式、章层级、起始值、引用前缀、刷新策略保存在文档自定义属性中。

## 安装

### 方式一：安装包（推荐）

从 `dist/` 取对应版本，例如 `eqnum-0.2.9-build1-linux.tar.gz`：

```bash
tar -xzf eqnum-0.2.9-build1-linux.tar.gz
cd eqnum-0.2.9-build1
bash install.sh
```

安装脚本会自动识别 WPS 的 `jsaddons` 目录（优先 `~/.local/share/Kingsoft/wps/jsaddons`），
也支持用 `WPS_JSADDONS_DIR` 手动指定。安装后需**完全退出并重启 WPS**。

### 方式二：源码目录

```bash
bash addon/install.sh
```

### 卸载

```bash
bash uninstall.sh        # 发布包内
bash addon/uninstall.sh  # 源码目录
```

## 使用

重启 WPS 后，在「插入」标签页的「公式编号」分组中打开右侧任务窗格：

1. 首次使用：把光标放到目标章节内，点「本章重编号」；或点「全文重编号」处理整篇。
2. 单个补充：「编号当前公式」。
3. 正文引用：「插入引用」选择公式编号；重编号后引用会自动跟随。
4. 「刷新引用」可单独刷新全文引用域。

建议先备份文档，在副本上验证排版效果。

## 环境要求

- WPS 文字 Linux 12.x
- 安装包需要 `bash` 与 `python3`（用于维护 `publish.xml`）
- 以当前登录用户身份安装，不要使用 `sudo`

## 已知限制

- 全文/本章重编号只处理「公式后面已有编号」的公式，未编号公式不会被自动补号。
- 同段多公式、非本工具表格内的公式、MathType 公式不处理。
- 正文中手打的纯文本引用（如 `式(1.1)`）不会自动替换，需人工核对。
- 批量处理受 WPS 每次编辑整篇重排的影响，大文档耗时较长，可用「中止」随时停止。
